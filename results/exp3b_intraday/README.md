# 第 2 层b：日内 5 分钟序列的拓扑指纹

**数据源**：baostock 5 分钟线（48 bar/日），120 只股票，2023-10-09 – 2026-09-30，
共 **87,115 个 (股票, 交易日) 样本**。

## 复现

```bash
# ① 下载 5 分钟线（可续跑；120 只约 22 分钟，单只 ~35s）
python src/fetch_intraday.py --n-stocks 120 --workers 4
#    缓存落在 data/intraday/<code>.parquet（91 MB，gitignore）

# ② 特征 + 评估
python src/experiment_3b_intraday.py --n-stocks 120 --workers 17 --tag n120_5min
```

## 结果

**T1 涨停日分类**（涨停日 635 个 / 0.729%；分层 5 折，每折只用训练集筛 top-30 特征）

| 特征组 | AUC |
|---|---|
| RAW | 0.9958 |
| TOPO+RAW | 0.9961 |
| TOPO+CLASSIC+RAW | 0.9943 |
| CLASSIC | 0.9922 |
| TOPO | 0.9301 |
| RING_only（单标量环数） | 0.7462 |

**T2 purged walk-forward IC（未来 5 日已实现波动）**

| 特征组 | IC | NW t |
|---|---|---|
| ALL | 0.2140 | 16.0 |
| TOPO+CLASSIC | 0.2089 | 14.4 |
| RAW | 0.2044 | 38.8 |
| TOPO+RAW | 0.1885 | 15.5 |
| CLASSIC | 0.1667 | 15.5 |
| TOPO | 0.1526 | 11.0 |

**⭐ 配对检验（折级 IC，5 折配对）—— 结论必须以此为准**

| 对比 | ΔIC | 胜出折数 | 配对 t | p |
|---|---|---|---|---|
| ALL − RAW | +0.0097 | 3/5 | +0.71 | **0.515** |
| TOPO+CLASSIC − RAW | +0.0045 | 3/5 | +0.30 | **0.777** |
| TOPO+RAW − RAW | −0.0159 | 2/5 | −1.17 | 0.306 |
| TOPO − RAW | −0.0517 | 0/5 | −3.23 | **0.032** |
| CLASSIC − RAW | −0.0377 | 0/5 | −3.00 | **0.040** |

→ **"ALL > RAW" 不成立**（p=0.52，只赢 3/5 折），不能称为增量。
→ TOPO 与 CLASSIC **单独都显著低于** RAW。
→ 与前两层一致：**拓扑特征没有超过强基线**；这里唯一的变化是它不再"拖累"。

**⚠️ 小样本教训**：20 只股票的冒烟版给出 ALL−RAW = −0.031（方向相反）。
5 折配对检验是小样本下唯一靠谱的判据，光比均值会被折间波动骗到。
